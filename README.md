# PDFMerger
A simple, lightweight, and efficient command-line tool to merge multiple PDF files into a single document, written in Python. 

*Why the name? Because it can merge a million PDFs! 😉

## Features
- **Interactive CLI:** Asks exactly how many files you want to merge.
- **Sequential Merging:** Combines PDFs in the exact order you specify.
- **Fast & Lightweight:** Powered by the reliable `PyPDF2` library.

## Prerequisites
Make sure you have **Python 3.x** installed on your machine. You will also need the `PyPDF2` library.
